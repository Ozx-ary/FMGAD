# FMGAD

Few-shot multi-class graph anomaly detection with multi-view subgraph encoding,
explicit anomaly evidence, and hierarchical prototypes.

## Structure

```text
main.py        Single-run training entry
train.py       Training, validation, and checkpoint selection
evaluate.py    Balanced episodic and full-pool evaluation
models/        FMGAD model components
data/          Loading, anomaly injection, splitting, and episode sampling
configs/       Nine dataset configurations
utils/         Configuration, metrics, random state, and file utilities
datasets/      Place source graph files here
```

## Installation

Use Python 3.10 or 3.11. Install a PyTorch build suitable for your device, then:

```bash
python -m pip install -r requirements.txt
```

## Data

Place MATLAB graph files in `datasets/`:
`Photo.mat`, `Tolokers.mat`, `Weibo.mat`, `CS.mat`, `Flickr.mat`,
`BlogCatalog.mat`, `Books.mat`, and `Questions.mat`.
PubMed downloads through PyTorch Geometric on first use.
See [datasets/README.md](datasets/README.md) for the required fields.

## Training

Run commands from this folder:

```bash
python main.py --config configs/books.yaml --seed 42 --device auto
python main.py --config configs/photo.yaml --data-root datasets --seed 42
```

Outputs are saved under `results/<dataset>/seed_<seed>/`, including the resolved
configuration, checkpoints, and test metrics. Checkpoint selection uses validation
macro-F1. Test labels are not used to select checkpoints.

## Evaluation

Use the configuration saved by training:

```bash
python evaluate.py --config results/books/seed_42/config.yaml --checkpoint results/books/seed_42/checkpoints/best_model.pt --split test --mode episodic
python evaluate.py --config results/books/seed_42/config.yaml --checkpoint results/books/seed_42/checkpoints/best_model.pt --split test --mode full
```

The four classes are normal, structural, attribute, and hybrid. Anomaly-type labels
are generated by synthetic injection. The default anomaly ratio is 5%, with type
proportions 0.4:0.4:0.2. The stratified train/validation/test split is 0.4/0.2/0.4;
Books uses 0.3/0.3/0.4. Two-shot means two support nodes per class in each episode,
not the total training label budget; labeled training queries also contribute to
optimization.

Episodic evaluation uses balanced, disjoint support and query sets within each
episode. Full evaluation uses support nodes from the training pool and all test
query nodes, preserving approximately 5% anomaly prevalence. These protocols use
different support sources and query distributions. Multi-class metrics use
one-vs-rest macro averaging; binary anomaly scores are `1 - P(normal)`.

Raw datasets and trained weights are not included.
